# Duck Hunt JS study copy

This repository contains a copy of the Duck Hunt JS project used for study and experimentation.

## Original project

The original implementation is maintained by Matt Surabian:

https://github.com/MattSurabian/DuckHunt-JS

The original project uses PixiJS, GreenSock, Howler and Bluebird to implement a browser-based Duck Hunt game.

## Why this repository exists

I kept this repository as a learning reference while studying browser rendering, animation, audio and game-loop structure.

I do not present the original Duck Hunt implementation as my own work.

For upstream documentation, issues and contribution history, use the original repository linked above.

## Running this copy

```bash
npm install
npm start
```

The local development server is normally available at:

```text
http://localhost:8080
```

The repository remains public primarily as historical learning material.
